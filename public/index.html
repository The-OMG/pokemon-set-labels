What this is

A free label press for Pokémon Trading Card Game collectors. Tick the expansions you own, choose a label size, and print binder or storage-box labels that carry the set symbol, the HD set logo, the expansion number, release date, generation and card count, including secret rares. It covers every English expansion from Base Set (1999) through the current Mega Evolution series, plus special sets, McDonald's promos, POP packs and Trick or Trade.

How to print

  1. Label printer roll (Phomemo M110 and similar): install Phomemo's Windows or Mac driver so the printer shows up as a normal printer, pick your roll under Label size, press Print labels. In the print dialog choose the Phomemo as the destination and check under "More settings" that Paper size shows your roll (the page is sized to the driver's exact numbers so it should be picked automatically), Margins None, Scale 100%, Background graphics on. Each label is its own page. The driver's "50 mm" sizes are really 48 mm, the width of the print head. No driver, or printing from a phone? Download PNGs gives you each label as a 203 dpi image for the Phomemo app.
  2. Color printer sheet: press Print sheet. Labels are laid out at true size on Letter, A4 or 3 × 5 index cards with optional cut guides. The Sheet preview shows the exact pages first.

Where the data comes from

Set names, expansion numbering, release dates, card counts, symbols and logos come from Bulbapedia's list of Pokémon TCG expansions; Base Set artwork from pokemontcg.io. The sequential expansion numbers count main-series sets and special sets separately. Data snapshot: . Missing a new set? Open an issue on GitHub.

Open source

Source code, data pipeline and issue tracker: github.com/The-OMG/pokemon-set-labels. Runs entirely in your browser; nothing you select is sent anywhere. Settings are remembered on this device only.
