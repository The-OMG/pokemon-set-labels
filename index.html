Sheet printing

Print sheet lays the selected labels at true size on a color printer; the Sheet preview shows the exact pages. Print labels sends one label per page at the roll size; pick the Phomemo M110 in the print dialog and set scale to 100%. For two labels per 3 × 5 card use the "Index card half" size with margin 0 and gap 0.
